# 내 차량 연결 해제 버튼 레이아웃 개선

마중 모바일 웹의 **내 정보 > 내 차량** 화면에서 차량 정보와 연결 해제 버튼을 구분하도록 레이아웃을 개선했다.

기존에는 차량 이름과 연결 해제 버튼이 같은 문단에 배치되어 좁은 화면에서 정보와 동작을 구분하기 어려웠다.

이번 변경은 차량 정보를 읽기 쉽게 표시하고, 모바일 화면에서 연결 해제 버튼을 안정적으로 배치하는 데 목적이 있다.

**변경 및 검증일: 2026년 10월 28일**

---

## 1. 변경 내용

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 차량 이름 | 연결 해제 버튼과 같은 영역 | 독립된 정보 영역 |
| 연결 상태 | 차량 이름·버튼과 함께 표시 | 차량 이름과 함께 표시 |
| 연결 해제 | 정보와 같은 문단 | 별도 동작 영역 |
| 좁은 화면 | 정보와 버튼이 혼재 | 버튼을 다음 줄 오른쪽에 배치 |
| 접근성 | 차량별 동작 구분 개선 필요 | 차량 이름을 포함한 접근성 이름 사용 |

### 개선 후 구성

차량 정보를 표시하는 영역과 실제 동작을 수행하는 영역을 분리했다.

- **정보 영역:** 차량 이름과 현재 연결 상태
- **동작 영역:** 차량 연결 해제 버튼

화면 너비가 좁아지면 버튼을 다음 줄에 배치하고 오른쪽으로 정렬한다.

기존 차량 이름과 연결 상태는 유지하면서 버튼 배치만 변경했다.

---

## 2. 모바일 반응형 처리

휴대전화처럼 화면 너비가 제한된 환경에서도 차량 이름과 버튼이 서로 겹치지 않도록 구성했다.

### 배치 기준

- 차량 이름과 연결 상태를 먼저 표시
- 연결 해제 버튼을 별도 영역에 배치
- 좁은 화면에서는 버튼을 다음 줄로 이동
- 버튼은 오른쪽 정렬
- 가로 스크롤이 발생하지 않도록 처리

## 3. 접근성 개선

차량 연결 해제는 특정 차량에 영향을 주는 동작이므로, 버튼의 접근성 이름에서 대상 차량을 구분할 수 있도록 했다.

예를 들어 차량 이름이 `내 차량`이라면 보조 기술에서 해당 차량의 연결 해제 동작임을 알 수 있어야 한다.

### 적용 기준

- 연결 해제 대상 차량 이름 포함
- 버튼이 수행하는 동작 명시
- 차량이 여러 대일 때도 대상 구분 가능
- 모바일에서 누르기 쉬운 버튼 크기 확보

이름만 다른 동일한 `연결 해제` 버튼이 반복되는 경우에도 사용자가 각 버튼의 대상을 구분할 수 있도록 했다.

## 4. 검증 결과

시험 계정을 사용해 너비 390px 화면에서 레이아웃을 확인했다.

| 검증 항목 | 결과 |
| --- | --- |
| 화면 너비 | 390px |
| 차량 정보·동작 영역 분리 | 확인 |
| 좁은 화면의 버튼 줄바꿈 | 확인 |
| 버튼 오른쪽 정렬 | 확인 |
| 가로 넘침 | 없음 |
| 버튼 높이 | 48px |
| 차량 이름을 포함한 접근성 이름 | 적용 |

이번 검증은 모바일 너비의 화면 배치 확인에 해당한다.

실제 휴대전화에서 다양한 화면 크기, 터치 동작 및 스크린 리더를 이용한 전체 접근성 검증을 완료했다는 의미는 아니다.

---

## 5. 기존 동작 유지

이번 변경은 화면 배치와 접근성 이름을 개선한 작업이다.

차량 연결 해제의 비즈니스 로직과 서버 API는 변경하지 않았다.

다음 흐름은 기존 동작을 유지한다.

1. 연결 해제 버튼 선택
2. 연결 해제 확인 화면 표시
3. 사용자 확인
4. 기존 API로 연결 해제 요청
5. 서버 응답에 따라 화면 갱신

레이아웃 검증 과정에서 실제 계정의 차량 연결을 해제하지 않았다.

따라서 이번 시험은 **UI 배치와 접근성 개선 확인**이며, 운영 차량 연결 해제 API의 실제 수행 검증과는 구분한다.
