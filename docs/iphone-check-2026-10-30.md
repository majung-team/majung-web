# 아이폰 화면 확인 · 2026년 10월 30일

실제 아이폰의 Chrome을 Mac의 iPhone 미러링으로 조작했다. Wi-Fi 연결 상태이며 QR은 사용하지 않았다. iOS 버전과 기기 모델은 이번 확인에서 조회하지 않았다.

## 확인한 내용

- 공개 HTTPS 첫 화면과 로그인 안내, 개인정보 처리방침 열기
- 로그인 후 승준 계정의 픽업·사람 찾기 화면 전환
- 존재하지 않는 마중 ID 검색 시 결과 없음 안내
- 입력 후 화면이 확대된 상태로 남는 현상 확인
- 검색 결과와 연결 목록이 비어 있어도 페이지 이동 영역이 표시되는 현상 확인

공통 입력 필드의 글자를 15px에서 16px로 바꾸고, 첫 페이지에 20개 미만의 항목이 있으면 페이지 이동 영역을 숨긴다. 뒤 페이지는 결과가 없어도 이전 페이지로 돌아갈 수 있도록 유지한다. 화면 확대 자체를 금지하는 설정은 추가하지 않는다.

## 아직 확인하지 않은 내용

현재 아이폰은 차량에 연결된 운전자와 같은 계정이고 연결된 사람이 없다. 다른 계정에 실제 요청을 보내거나, 초대 참여·장소 제안·준비 완료·종료까지 완료한 것으로 기록하지 않는다. 실제 휴대전화의 알림 수신, LTE 전환, 실차 동작도 미확인이다.

재접속·장소 제안·SSE 관련 자동 검사는 실기기 확인과 별개다. 개인 계정 식별자나 초대 토큰이 있는 캡처는 저장소에 올리지 않는다.
