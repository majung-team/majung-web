# 탑승자 자동 연결

기능: 2.1 자동 연결. 서버 API는 [majung-backend 자동 연결과 끊기](https://github.com/majung-team/majung-backend/blob/main/docs/auto-connect.md)를 따른다.

- 차량 QR로 받은 초대 링크의 참여 화면에서 이름을 받지 않는다. 참여하기를 누르면 바로 연결되고 위치·ETA와 준비 상태 화면이 열린다.
- 링크를 여는 것만으로는 연결하지 않는다. 메신저 미리보기나 링크 검사로 초대가 소비되는 것을 막으려고 참여하기 버튼은 남겼다.
- 초대 링크는 한 사람만 쓸 수 있다. 이미 사용된 링크는 "초대가 만료되었거나 이미 사용됐습니다"로 거절된다.
- 운전자가 탑승자를 끊거나 초대를 다시 만들면 탑승자 화면은 다음 조회에서 처음 화면으로 돌아가고 "운전자가 연결을 끊었거나 초대가 다시 발급됐을 수 있어요"를 보여준다.
- 개발용 운전자 화면(`운전자 확인 화면`)에는 **탑승자 끊기** 버튼을 두었다. 실제 끊기 조작은 차량 앱에서 한다.
- 이전에 `WAITING_APPROVAL`로 남은 픽업을 위해 승인 화면 코드는 남겨 두었다. 새 참여는 이 상태를 거치지 않는다.

## 확인 범위

로컬 서버와 헤드리스 Chrome에서 확인했다: 이름 입력 없음 → 참여 → 서버 상태 `ACTIVE`(이름 `탑승자`) → 운전자 끊기 → 탑승자 화면 안내와 복귀 → 새 초대로 다른 사람이 참여 → 이전 링크 거절. 실제 휴대전화·차량 연동은 확인하지 않았다.
