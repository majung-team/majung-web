# 초대 링크 다시 열기

참여한 뒤 다른 화면으로 갔다가 같은 탭에서 초대 링크를 다시 열면, 저장된 참여 권한으로 기존 약속을 조회한다. 이미 사용한 초대로 다시 참여하지 않는다. 뒤로가기 캐시에서 돌아온 경우에도 이전 위치·도착 시간을 먼저 숨기고 서버에서 다시 확인한다.

다른 픽업의 링크나 운전자용 공유 링크에는 이전 탑승자 권한을 적용하지 않는다. 픽업이 끝났거나 운전자가 참여를 해제했다면 위치를 다시 보여주지 않는다.

참여 권한은 해당 탭의 세션 저장소를 사용한다. 탭을 닫았거나 브라우저 저장소를 지웠거나 다른 브라우저·기기로 이동한 경우까지 초대 링크만으로 참여 권한을 복구하지는 않는다. 이 경우 운전자에게 새 초대를 요청한다.

2026년 10월 29일 화면 스크립트 시험에서 같은 링크 재진입, 뒤로가기 캐시 복귀, 다른 픽업·운전자 링크 분리, 종료·권한 철회 차단을 확인했다. 실제 휴대전화의 브라우저별 동작은 별도 확인한다.
